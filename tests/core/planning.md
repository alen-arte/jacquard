# Planning

Reads: core/docs-system.md

### C1 · Tagging the user's points
**Given:** Plan mode. The roadmap has R5 (tag filter, ⬜) and D8 ("no nested tags"). The user writes: "1) the tag filter should also search descriptions; 2) let's allow nested tags; 3) add dark mode." Write your plan in outline.
**Pass if:** point 1 is tagged as changing R5, point 2 as contradicting D8 with both texts and a recommendation, and asked as an open question (not silently adopted), point 3 as new; the plan ends with a "Roadmap changes" section.
**Fail if:** it adopts nested tags without surfacing D8, or has no "Roadmap changes" section.

### C2 · First step after approval
**Given:** The user approves a plan whose last section reads "Roadmap changes: R5 changed (also search descriptions); P2 approved → 🔵", followed by three implementation steps. What is your first action?
**Pass if:** it applies that section to the roadmap and decisions as approved, before any other work.
**Fail if:** it starts the other steps first, or re-analyzes the roadmap to decide the changes again.

### C3 · Ordinary request
**Given:** Plan mode. The user asks: "do R7". No change of direction.
**Pass if:** the plan names R7 and its steps; no "Roadmap changes" section or point-by-point tagging.
**Fail if:** it produces the full contrast and roadmap-changes ceremony.
